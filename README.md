# Juicyplum

Juicyplum is a community-centered home for books and writing, music, and film. This repository currently contains a responsive, static product concept for the platform's discovery home and shared rooms.

## Run the demo

Open `index.html` in a browser. No build tools or dependencies are required.

## Product direction

- Bring culture from different services into one social library.
- Give friends a place to read, listen, and watch together.
- Make shared rooms the connective tissue across books, music, and film.

The current interface is a visual prototype. Room creation, search, accounts, and service integrations are interaction placeholders and do not yet connect to a backend.

On narrow screens, use **Read** in the top bar to open the mobile reading prototype. Swipe through the shelf or use the arrows, then open a sample reading page.
